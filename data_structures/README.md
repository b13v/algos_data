# Data Structures

Ways of organizing data so that operations (access, insert, delete, search) are efficient. The cost of these operations is what we measure in [complexity analysis](../algorithms/foundations/complexity_analysis/).

## Structures

- **Arrays** — contiguous indexed storage
- **Linked Lists** — nodes connected by pointers
- **Stacks** — last-in, first-out (LIFO)
- **Queues** — first-in, first-out (FIFO)
- **Hash Tables** — key to value with average O(1) lookup
- **Trees** — hierarchical data, binary search trees, traversals
- **Heaps** — tree-based priority queues
- **Graphs** — vertices and edges
- **Tries** — prefix trees for strings

Follow the order in the [curriculum](../CURRICULUM.md).
