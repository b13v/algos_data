# Algorithms

Step-by-step procedures for solving problems. Start with [complexity analysis](foundations/complexity_analysis/) so you can reason about *how good* an algorithm is before learning the algorithms themselves.

## Categories

- **Foundations** — [Complexity Analysis](foundations/complexity_analysis/) (Big-O)
- **Sorting** — bubble, selection, insertion, merge, quick, heap, counting
- **Searching** — linear, binary
- **Recursion** — base cases, recursive thinking
- **Graph algorithms** — BFS, DFS, Dijkstra
- **Greedy** — making locally optimal choices
- **Dynamic programming** — memoization and tabulation
- **String algorithms** — pattern matching basics

Follow the order in the [curriculum](../CURRICULUM.md).
